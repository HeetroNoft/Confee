# Confee: improvements noted while porting Infernal Mobs

Each item says what was missing in Confee, how Infernal Mobs works around it, and what to add to Confee.

All the items noted so far (item stack option, search by name, KEEP on file errors, mob drawing, tiled textures,
stack icons, `PreviewContext#path()`, section previews, scoreboard suggestions, theme color helpers,
`ConfeeTextField`) are in Confee 0.3.0.
